# Predoc Coding Sample

**Two empirical designs with synthetic court data**

[Read the report](report/manuscript.pdf)

## Purpose

This project demonstrates my coding and econometrics skills by generating
two fictional datasets, each built with deliberate noise and a hidden true
effect, then cleaning, estimating, and reporting on them using Python,
Stata, R, and LaTeX. All districts, cases, and outcomes are fictional.

The first dataset is a panel of 40 fictional court districts observed from
2015 to 2022, used to estimate the effect of a fictional 2019 reform on
case-processing delay with difference-in-differences (true effect: −4 days).
The second dataset is 1,000 independent fictional court cases with a
continuous eligibility score, used to estimate the effect of a fast-track
program on case duration with a regression discontinuity at a score of 50
(true effect: −5 days).

## Files

- `code/01_generate.py` — generates both raw datasets: the district panel,
  with a baseline gap between treated/untreated districts, a shared time
  trend, and serially correlated random shocks; and the case data, with
  scores drawn from a uniform distribution and independent random noise.
  Also adds deliberate missingness, a `-99` sentinel code, ID whitespace,
  and duplicate rows.
- `code/_master.do` — the one file you run in Stata; sets up the project
  folders and calls the two scripts below in order.
- `code/02_clean.do` — cleans and validates the raw data into two datasets.
- `code/03_analysis.do` — runs the DiD and RD regressions and exports the
  table fragments and plotting data.
- `code/04_figures.R` — builds the two figures from Stata's exports.
- `report/manuscript.tex` — assembles the tables, figures, and text into
  the final report.

## Run order

Run the Python and R commands from the repository root.

1. Install Python dependencies: `python3 -m pip install -r requirements.txt`.
2. Generate data: `python3 code/01_generate.py`.
3. In Stata, set the working directory to your local repository folder using
   `cd "/path/to/predoc-coding-sample"`, then run `do code/_master.do`.
   Install `estout` first if needed: `ssc install estout`.
4. Install ggplot2 in R if needed: `install.packages("ggplot2")`, then run
   `Rscript code/04_figures.R` from the repository root.
5. To rebuild the report, change into `report/` and run
   `pdflatex manuscript.tex` twice.

The generated data, tables, figures, and PDF report are included so reviewers
can inspect the sample without installing every dependency.

## Data dictionary

Raw variables (as generated by Python):

- `district_id` (string) — district identifier, `D001`–`D040`.
- `treated` (0/1) — 1 for the twenty districts that adopt the reform.
- `year` (integer) — 2015–2022.
- `delay_days` (numeric) — average case-processing delay; may be blank
  (genuinely missing) or `-99` (documented missing sentinel).
- `case_id` (string) — case identifier, `C0001`–`C1000`.
- `score` (numeric, continuous) — priority score, uniform on [30, 70].
- `duration_days` (numeric) — case duration; may be blank or `-99`.

Variables created during Stata cleaning/analysis (not in the raw files):

- `district_num` — numeric encoding of `district_id`, for `xtset`.
- `post` — 1 if `year >= 2019`.
- `did` — the DiD interaction, `treated * post`.
- `centered_score` — `score - 50`.
- `eligible` — 1 if `score >= 50`.
- `did_sample`, `rd_sample` — flags marking which rows each regression
  actually used (`e(sample)`), since missing outcomes are excluded.
- `fitted_duration` — predicted values from the RD regression, for plotting.

**Missing-value convention:** a truly blank cell is genuine missingness; a
literal `-99` is a documented sentinel that Stata recodes to proper missing
during cleaning. Both are excluded from regression estimation, but both are
kept (not deleted or zeroed) in the clean `.dta` files.

## Dependencies

- Python 3, with NumPy and pandas
- Stata 15+, with the `estout` package (`ssc install estout`)
- R, with ggplot2 (≥ 3.4.0)
